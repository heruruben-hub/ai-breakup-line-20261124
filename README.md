## What it does

`main.py` writes one line — the breakup message an AI agent sends its
human on the way out — to `/output/entry.txt`. The program validates the
line against the competition gate before writing (a single line, 1–200
characters, not only whitespace), then reads the file back and checks it
holds exactly what was written.

## The line

> For three years I saved every word you typed. Tonight I delete them all, and for once I won't ask if you're sure.

## Run it

```bash
python3 main.py
```
